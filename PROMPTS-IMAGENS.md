# Prompts das imagens — Stay Fit Academia

**Onde salvar:** `src/assets/img/site/`, com **exatamente o nome indicado** (extensão .jpg, .png,
.webp ou .avif). Depois rode `npm run otimizar` (converte para WebP leve) e `npm run build`.
Se trocar a `hero`, rode também `npm run og`.

Os prompts descrevem o visual real da academia, visto nos reels: **paredes e teto pretos, estruturas
de aço pintadas de amarelo, luminárias hexagonais de LED no teto, setas de neon amarelas (">") nas
paredes e piso emborrachado preto com detalhes amarelos**. Todos pedem **sem texto e sem logos**.

Situação atual de cada imagem:
- ✅ **provisória**: imagem da Princesa Fitness recolorida para amarelo (já aparece no site; dá para manter ou trocar)
- ⬜ **faltando**: hoje o site mostra um card gráfico amarelo no lugar
